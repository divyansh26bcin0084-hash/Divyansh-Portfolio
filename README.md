## 🏗️ Design & Architecture

The portfolio blends an **elite architectural-tech** aesthetic with subtle esports energy:
- **Obsidian & Graphite Palette**: Deep `#06070a` dark canvas with graphite glass panels (`backdrop-filter: blur(16px)`).
- **Cinematic Lighting & Highlights**: Glowing cobalt blue (`#2563eb`), vivid violet (`#7c3aed`), and restrained cyan accents (`#22d3ee`).
- **Interactive 3D Three.js Hero**: Generative floating parametric architectural structure with glowing vertices, isometric blueprint ground grid, elevation contour rings, and smooth mouse-parallax tracking.
- **Client-Side Photo Preview**: Interactive portrait placeholder allowing local image preview and drag-and-drop.
- **Scrollspy Navigation**: Sticky transparent header with active-section tracking across all 7 sections.

## 🚀 How to Enable GitHub Pages

To make this portfolio accessible online via GitHub Pages:
1. Go to your repository settings on GitHub: `https://github.com/divyansh26bcin0084-hash/Divyansh-Portfolio/settings/pages`
2. Under **Build and deployment** > **Source**, select **Deploy from a branch**.
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. In ~1-2 minutes, your website will be live at:
   `https://divyansh26bcin0084-hash.github.io/Divyansh-Portfolio/`
